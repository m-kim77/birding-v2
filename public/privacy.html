탐조일지 개인정보처리방침

시행일: 2026년 9월 27일

탐조일지(birding-v2.vercel.app)는 새를 본 기록을 남기는 무료·비상업 웹앱입니다. 회원가입이 없고, 기록과 사진을 이 사이트의 서버에 저장하지 않습니다.

1. 기록과 사진은 내 기기에

기록(새 이름·날짜·장소·좌표·메모)과 사진은 사용하는 브라우저 안에만 저장됩니다. 운영자는 이 내용을 볼 수 없습니다.

2. 구글 드라이브 동기화 (켰을 때만)

  • 설정에서 '구글로 로그인'을 누르면 내 구글 드라이브의 '탐조일지 동기화' 폴더에 기록과 사진의 사본이 올라갑니다. 다른 사람의 드라이브나 운영자에게는 가지 않습니다.
  • 요청하는 권한은 이 앱이 만든 파일만 보고 고치는 권한(drive.file) 하나입니다. 드라이브의 다른 파일은 읽을 수 없습니다. 이름·이메일·프로필은 요청하지 않습니다.
  • 기록과 사진은 브라우저에서 구글 드라이브로 곧장 가고, 이 사이트의 서버를 거치지 않습니다.
  • 이 사이트의 서버는 로그인을 이어 가는 열쇠(갱신 토큰)만 다룹니다. 열쇠는 암호화해서 내 브라우저의 쿠키에만 두고, 서버·데이터베이스·로그에 남기지 않습니다.
  • 설정의 '연결 끊기'를 누르면 구글에 권한 철회를 요청하고 쿠키를 지웁니다. 구글 계정의 연결된 앱에서도 언제든 끊을 수 있습니다. 드라이브에 올라간 사본은 내 드라이브에서 직접 지울 수 있습니다.
  • 구글 API에서 받은 정보는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따라, 동기화 기능을 제공하는 데에만 씁니다. 광고에 쓰거나 남에게 넘기지 않습니다.

3. 기기 밖으로 나가는 그 밖의 것

  • 장소 이름 찾기: 기록의 좌표(약 11m 단위)가 이 사이트의 서버를 거쳐 OpenStreetMap(Nominatim)으로 갑니다. 기록에 남기지 않고, 같은 자리를 다시 묻지 않도록 돌아온 장소 이름만 하루 동안 캐시합니다.
  • AI 판정: 'AI에게 물어보기'를 누를 때만, 새로 만든 사진(위치 정보 없음)과 촬영 시각·장소 이름이 갑니다. 기본 제공 AI는 이 사이트의 서버를 거쳐 운영자의 컴퓨터로, 내 API 키를 쓰면 그 서비스로 곧장 갑니다. 운영자는 판정에 받은 사진을 따로 모아 두지 않습니다.
  • 위키백과·지도·글꼴: 판정 근거 검색어, 보고 있는 지도 구역, 글꼴 파일 요청이 각 서비스로 갑니다.

앱의 설정 화면 '무엇이 어디로 가나요'에 같은 내용이 더 자세히 있습니다.

4. 쿠키

드라이브 동기화를 켠 경우에만 로그인 열쇠를 담은 쿠키 하나를 둡니다(이 사이트 안에서만 쓰이고 다른 사이트로 가지 않습니다). 광고·분석용 쿠키는 쓰지 않습니다.
