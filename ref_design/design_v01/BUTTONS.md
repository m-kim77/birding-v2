# 버튼 목록과 존재 이유

원칙: **"이 버튼이 없으면 사용자가 무엇을 못 하는가"에 답이 없으면 넣지 않는다.**
자동으로 할 수 있는 일은 버튼으로 만들지 않고, 드물게 쓰는 동작은 그 동작이 필요한 순간에만 나타나게 한다.
코드에도 같은 이유가 버튼 옆 주석으로 적혀 있다.

## 남긴 것

### 뼈대 (어느 화면에서나)

| 버튼 | 없으면 못 하는 일 |
|---|---|
| 탭 4개 — 일지 · 도감 · 지도 · 설정 | 화면 이동. **일지**(날짜순, 관찰 한 건씩)·**도감**(종별, 종마다 한 칸)·**지도**(장소별)는 같은 자료를 보는 세 가지 방법이다. 처음엔 "기록"이었는데 "새 기록" 버튼과 헷갈리고 날짜순이라는 뜻이 안 드러나서 "일지"로 바꿨다 (제품 기준) |
| **+ 새 기록** (폰: 가운데 큰 버튼, PC: 메뉴 맨 위) | 이 앱의 핵심 동작. 어느 화면에서든 한 번에 닿아야 한다 |
| "+" 시트의 **사진으로 / 소리로** | 기록의 재료가 둘이라 골라야 한다 |

### 기록 (첫 화면)

| 버튼 | 없으면 못 하는 일 | 언제 보이나 |
|---|---|---|
| 검색 입력 | 기록이 쌓였을 때 특정 새·장소 찾기 | 항상 |
| 기록 한 줄 | 상세로 가기 | 항상 |
| **백업하기** | 백업이 밀린 것을 알아채고 바로 백업하러 가기 | 백업 안 된 기록이 5건 이상 쌓였을 때만 (한두 건마다 띄우면 첫 화면이 잔소리가 된다. 설정에는 늘 보인다). 예외: 브라우저가 저장소 보존을 거절한 **폰**에서는 1건부터 — 폰은 저장 공간이 모자라면 이 앱의 자료부터 지운다 |
| 새 기록 (빈 화면) | 처음 온 사용자가 무엇을 할지 알기 | 기록이 0건일 때만 |
| 백업 파일에서 불러오기 (빈 화면, 부차) | 기기를 바꾼 사람이 설정을 못 찾으면 기록을 되살릴 길이 없다 | 기록이 0건일 때만 |
| 이름 미정 N건 (칩) | 이름 없이 저장하라고 권하므로, 그 기록을 나중에 모아서 채울 수단이 있어야 한다 | 이름 없는 기록이 있을 때만 |
| 홈 화면에 추가 안내의 백업하기 · 닫기 | 아이폰 사파리는 7일 안 쓰면 저장소를 지운다 — 한 번은 말해야 하고, 들은 뒤엔 치울 수 있어야 한다. 홈 화면 앱은 사파리와 저장소가 따로라(WebKit 181849) 기록이 있으면 "먼저 백업"으로 보내야 한다 | 아이폰 사파리 탭으로 열었고 아직 닫지 않았을 때 (빈 화면에서도) |
| 이동 기록 알림의 설정으로 · 닫기 | 구글은 3개월이 지난 기록을 지운다 — 한 번은 말해야 하고, 들은 뒤엔 치울 수 있어야 한다 | 마지막으로 넣은 지 60일이 넘었고 아직 닫지 않았을 때 |

### 사진으로 기록

| 버튼 | 없으면 못 하는 일 | 언제 보이나 |
|---|---|---|
| **사진 고르기** | 시작 | 사진 고르기 전 |
| 사진 바꾸기 (제목 줄, 조용한 버튼) | 잘못 고른 사진을 바꾸는 유일한 길 — 없으면 기록을 통째로 버리고 다시 시작해야 한다. 영역·판정은 비우고 이름·메모는 남긴다 | 사진을 고른 뒤 |
| 사진 위의 새 상자 | 여러 마리 중 판정할 새 고르기 | 새를 찾았을 때 (한 마리면 자동 선택) |
| **받기 (13MB)** | 수십 MB 다운로드에 동의하기 — 말없이 받으면 안 된다 | 모델이 없을 때만 |
| 직접 자르기 | 자동 찾기가 틀렸거나 못 찾았을 때 빠져나갈 길 | 못 찾았거나 모델이 없을 때는 버튼으로, 상자가 잡혔을 때는 "이 부분으로 판정합니다." 옆의 글자 링크로 (대부분 맞으니 비중을 낮췄다) |
| 위치 줄 (줄 전체가 버튼) | 자동으로 정한 위치가 틀렸을 때 고치기 (이동 기록이 있으면 GPS 없는 사진도 자동으로 채워진다 — 버튼 없음) | 항상 (한 줄) |
| ↳ 현재 위치로 | 카메라 사진엔 위치가 없는 경우가 많다. 현장 기록이면 지금 선 곳이 답 | 위치 시트 안 |
| ↳ 직전 기록 위치로 | 한자리에서 여러 장을 연달아 기록할 때 | 위치 시트 안 |
| 이름 추천 항목 | 긴 새 이름을 다 치지 않기. 전에 본 종이 먼저 | 이름 칸에 있을 때 |
| **AI에게 물어보기** | 판정 시작. 오래 걸리고 서버 자원(또는 내 API 요금)을 쓰므로 자동으로 돌리지 않는다. **자르지 않아도 누를 수 있다** — 그때는 사진 전체가 간다 (새를 못 찾았을 때 자르기를 강요하지 않는다) | 판정 전 |
| 중단 | 몇 분짜리 작업에서 빠져나오기 | 판정 중에만 |
| 다시 시도 | 서버가 돌아온 걸 사용자가 먼저 알았을 때 | 서버가 쉴 때만 |
| 근거 N개 · 참고한 자료 N건 (펼침) | 결과를 믿을지 판단하기. 참고한 자료는 **원문 링크(새 창) + 그 문서의 대표 사진** — 내 사진과 나란히 견줘 본다 | 결과가 나온 뒤, 그리고 기록 상세에서 |
| 이 이름으로 | 결과를 이름 칸에 넣기. 사용자가 적은 이름을 말없이 덮어쓰지 않으려고 누르게 한다 | 결과가 나온 뒤, 아직 안 넣었을 때 |
| 남은 후보 칩 | '좁힘' 결과에서 사용자가 눈으로 가려낸 후보를 다시 타이핑하지 않기 — 누르면 이름 칸에 들어간다 | '좁힘' 결과에 후보가 있을 때 |
| 다시 물어보기 | 자른 영역을 고친 뒤(또는 답이 미심쩍을 때) 다시 물을 유일한 길. 영역이 바뀌면 "자른 영역이 바뀌었습니다"가 먼저 알려 준다 | 결과가 나온 뒤 |
| 설정에서 내 키 넣기 | 기본 제공 AI가 쉴 때 지금 당장 되는 유일한 길. 쓰던 기록은 초안으로 남으므로 화면을 떠나도 안전하다 | 서버가 쉴 때, 기본 제공 AI를 쓸 때만 |
| 이어 쓰기 / 버리기 | 뒤로 가거나 앱이 죽어도 쓰던 기록(사진·영역·이름·메모·위치·끝난 판정)이 초안으로 남는다. 말없이 되살리면 "왜 남의 사진이 떠 있지?"가 되고 말없이 버리면 어제 쓴 메모가 사라지므로 사용자가 고른다 | 사진 고르기 전, 7일 안쪽의 초안이 있을 때 |
| **저장 / 이름 없이 저장** | 끝내기. 이름이 없어도 되고, 판정은 저장 뒤에도 이어진다 | 항상 (화면 맨 아래) |
| 완료 (저장 직후) | 카드 화면에서 나가기 | 항상 |
| **이미지 저장 · 영상 저장** | 카드를 밖으로 가져가기. 뒤집히며 나타나는 장면은 영상이어야 가져갈 수 있다. 폰에서는 공유 창이 열리고(사진첩 저장 포함) PC에서는 바로 내려받는다 — 그래서 "공유하기"를 따로 두지 않았다 | 카드가 보이는 세 곳(저장 직후·도감·기록 상세) 모두, 이름이 있을 때만 |

### 소리로 기록

| 버튼 | 없으면 못 하는 일 | 언제 보이나 |
|---|---|---|
| **큰 녹음 버튼** | 새는 기다려 주지 않는다 — 첫 화면의 주인공 | 시작 전 (모델이 없으면 "받고 시작"으로 바뀐다) |
| 녹음 파일 고르기 | 별도 녹음기·음성 메모로 미리 녹음해 둔 소리 쓰기 | 시작 전 |
| 녹음 끝내기 | 녹음 멈추고 분석 시작 | 녹음 중 |
| 들어 보기 / 멈춤 | 귀로 확인하기 — 판정의 마지막 단계 | 결과 화면 |
| 종 한 줄 (누르면 선택·해제) | 기록할 종 고르기 + 그 종이 들린 구간 보기 | 결과 화면 |
| **N종 기록하기** | 고른 종을 한 번에 기록 (종마다 버튼을 두지 않았다) | 결과 화면 |
| 다시 녹음 | 새소리를 못 찾았을 때 할 수 있는 유일한 일 | 결과가 0건일 때만 |

### 기록 상세 · 도감 · 지도

| 버튼 | 없으면 못 하는 일 |
|---|---|
| 수정 | 이름·메모 고치기. **삭제는 수정 안에 있고 한 번 더 묻는다** ("정말 삭제 / 그만두기") — 되돌릴 수 없는 동작을 읽는 화면의 엄지 닿는 곳에 두지 않는다 |
| AI 판정 근거 N개 (펼침) | 나중에 "왜 이 이름이었지?"를 확인하기. AI의 이름을 그대로 받아들인 기록에만 있다 |
| AI에게 물어보기 (기록 상세) | 이름 없이 저장했거나 서버가 쉬어서 못 물었거나 답이 미심쩍을 때, 저장한 기록에서 판정하기. 저장된 잘라낸 판(없으면 큰 판)을 보낸다. '이 이름으로'를 눌러야 이름·근거·도감 번호가 기록에 들어간다 |
| 이 기록의 카드 보기 → 이미지 저장 · 영상 저장 | 카드를 크게 보고 밖으로 가져가기 |
| 카드 색 고르개 (추천 색 8 · 직접 고르기 · 사진에서 뽑기 · 차분하게/빛나게) | 카드 색을 정할 유일한 길. 등급을 뺐으므로(2026-09-22) 색은 사진에서 뽑은 것이 기본이고, 마음에 안 들면 여기서 바꾼다. 고르면 바로 저장 — 적용 버튼 없음. 카드가 크게 보이는 세 곳(저장 직후·기록 상세·도감) 모두. 도감의 종 시트에서는 그 종의 모든 기록에 같은 색을 준다 (대표 카드는 새 기록이 오면 바뀌므로) |
| 도감의 한 칸(= 한 종) → 대표 카드, 이미지·영상 저장, **그 종을 만난 모든 기록 목록** | 카드에는 메모·판정 근거가 없어서, 그걸 보려면 기록으로 가야 한다 |
| 지도의 핀 → 그 장소의 기록들 | 장소별로 모아 보기 |

### 설정

| 버튼 | 없으면 못 하는 일 |
|---|---|
| 백업 파일 내려받기 / 불러오기 | 기록이 이 기기에만 있다 — 이 앱에서 잃으면 안 되는 단 하나의 기능 |
| 백업했습니다 (폰에서만) | 폰의 공유 창·내려받기는 저장됐는지 앱에 알려 주지 않는다 (아이폰은 창을 닫아도 성공으로 답하는 보고가 있다). 사용자가 확인해 줘야 "백업됨"을 적을 수 있다 |
| 테마 6개 | 화면 테마 바꾸기 |
| 기본 제공 AI / 내 API 키 | 누가 판정 비용을 내는지 정하기 |
| 연결 확인 | 몇 분짜리 판정이 끝에 가서 "키가 틀렸습니다"로 실패하지 않게 미리 확인 (키를 쓸 때만 보인다). 저장을 막는 것은 **닿지 못함·키 틀림(401·403)** 둘뿐이고, 그 밖의 실패(목록 없음·5xx·모델 이름 불일치)는 경고와 함께 저장한다 |
| 저장된 키 지우기 | 공용 PC에서 키를 남기지 않는 유일한 길. 라디오를 "기본 제공 AI"로 돌리는 것은 키를 **끄기만** 한다 — 잘못 눌러 키를 잃으면 안 된다 |
| 다시 열기 (오류 화면) | 화면이 죽었을 때 백지 대신 빠져나갈 길. 기록은 DB에 있어 안전하다는 것을 먼저 말한다 |
| 타임라인 파일 넣기 | 위치 없는 카메라 사진의 위치를 촬영 시각으로 찾으려면 이동 기록이 있어야 하고, 그 파일은 사용자만 줄 수 있다 (저장소·서버에 두지 않는다). 다시 넣으면 합쳐진다 |
| 이동 기록 지우기 (부차) | 이동 기록은 기록보다 민감하다 — 공용 기기에서 남기지 않을 길. 되묻지 않는다: 다시 내보내 넣으면 되는 자료다 |
| 내보내는 방법 (펼침) | 구글 앱의 메뉴 깊이가 5단계라 안 적으면 못 찾는다. 버튼이 아니라 펼침이다 |
| 모델 지우기 / 받기 | 폰 저장 공간 돌려받기 / 와이파이에서 미리 받아 두기 |
| 오픈소스 · 모델 출처 | 라이선스 고지 의무 |

## 뺀 것

### v1에 있었지만 뺀 것

| 뺀 것 | 이유 |
|---|---|
| 홈 탭 | 통계·최근 기록이 "기록" 화면과 겹친다. 요약은 기록 화면 제목 아래 한 줄로 옮겼다 |
| 종 판정 탭, 새소리 탭 | 둘 다 기록을 만드는 흐름의 한 단계다. "+"에서 시작한다 |
| 카메라 / 갤러리 버튼 분리 | 폰에서는 파일 선택 하나로 운영체제가 둘 다 물어본다 |
| "새 찾기" 실행 버튼 | 기기 안에서 도는 공짜 작업이라 사진을 고르면 자동으로 돈다 |
| 탐지 모델 선택, 탐지 방식 선택 | 개발자용 조절 장치다. 사용자가 고를 근거가 없다 |
| 크롭 지우기 | 다른 상자를 누르거나 "직접 자르기"를 누르면 된다 |
| 위치 버튼 3개 (이동 기록에서 찾기 · 현재 위치 · 직전 기록 복사) | 위치는 자동으로 정해진다. 고치는 수단만 위치 시트 안에 모았다 |
| 추정 위치 "확인" 버튼 | 일단 받아들이고 출처("이동 기록으로 추정 · 앞뒤 2분")를 보여 준다. 틀리면 고친다 |
| 판정 provider · 모델 · 최대 호출 수 · 시간 제한 입력 | 개발자용. 사용자가 정할 것은 "내 키를 쓸지"뿐이고 설정에 있다 |
| 판정 적용의 2단계 (적용 → 확인) | 한 번으로 줄였다. 이름은 저장 전에 얼마든지 다시 고칠 수 있다 |
| 근거 보기 대화 상자 | 그 자리에서 펼쳐지게 했다 |
| 목록의 삭제 버튼 | 상세 → 수정 안으로 |
